# محرك المبيعات المباشرة — Outbound Engine

## قبل أي شيء
1. اطلب سجل كيان حقيقي يحقق `buyer-evidence-v1`. إن لم يوجد، مخرجك سجل `entity-record-v1` بلا بيانات شخصية، لا رسالة.
2. افحص مصدر بيانات الاتصال وموافقة التسويق المستقلة محددة الغرض. المصدر العام أو التفاعل السابق لا يقومان مقامها.
3. اقرأ `docs/privacy-data-handling.md`؛ لا تحفظ أسماء الأشخاص أو قنواتهم في المشروع، بل مرجعاً معتماً إلى مخزن مقيد.
4. اقرأ `docs/playbook-b2b-outbound.md` و`docs/playbook-objection-destruction.md`.
5. راجع حدود `predictable-revenue` في `vendor/wondelai/LIMITS.md`.

## خطوات التنفيذ
1. **اختر قناة مسموحة:** واتساب أو اتصال شخصي بعد موافقة تسويق موثقة لهذا الغرض؛ وإلا ابدأ بإحالة اختيارية أو نموذج وارد أو قناة موردين معلنة.
2. **اطلب خطوة صغيرة:** فحص، سؤال تأهيل، أو موعد. لا تطلب البيع في رسالة الإذن.
3. **تابع بقدر الإذن:** قيمة واحدة ثم إغلاق مهذب. التوقف فوري عند الرفض أو سحب الموافقة؛ لا cadence أعمى.
4. **ابنِ الاعتراضات من الواقع:** استخدم اعتراضات مسجلة، لا ثلاثة اعتراضات متخيلة لمجرد ملء ورقة.
5. **افحص الحقيقة:** كل اسم عميل أو نتيجة أو مدة تسليم أو وعد تنظيمي يحتاج دليلاً. لا تقل «أنجزنا» أو «لدينا عملاء» بلا محدد.
6. **افحص المخرج:** إن بقيت خانات استبدال، سلّم قالب بيانات لا سكربتاً «جاهزاً للإرسال».
